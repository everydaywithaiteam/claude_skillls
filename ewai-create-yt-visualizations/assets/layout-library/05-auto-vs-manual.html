Manual

Default
“Ask me before acting.”
Claude pauses. You review the action, then choose Allow or Deny.
Use for: messages sent as you, money, sensitive accounts, important file changes.

Auto

Continuous
“Keep working, but safety-check actions.”
Checks can allow, block, reroute, or pause an action for your input.
Use for: low-risk research, drafting, and reversible work.

Higher stakes = more supervision.
